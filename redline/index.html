The pattern

AI builders are great at features. They skip the parts that don't demo well.

These three show up in almost every vibe-coded app we've looked at — because they're invisible until someone goes looking.

Critical

Secrets in the client bundle

Live API keys and service-role tokens get pasted straight into frontend code, because that's the fastest way to make the demo work.

const supabase = createClient( url, "sk_live_51Hc9...FULL_KEY" )
Warning

No row-level auth

Tables get created and queried directly from the client. Any signed-in user can read, and often write, every other user's rows.

.from('orders') .select('*') // no policy, no owner check
Warning

Trusting the request

Prices, quantities, and permissions get read straight off req.body instead of recomputed on the server.

const { amount } = req.body await charge(user, amount)
